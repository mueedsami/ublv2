# V2.1.1 Master Commit Fix

## Root cause
Supabase/PostgREST rejected the full-master replacement RPC because the function used DELETE statements without an explicit WHERE clause.

Old:
```sql
delete from public.product_account_ids;
delete from public.products;
delete from public.basepacks;
```

Fixed:
```sql
delete from public.product_account_ids where true;
delete from public.products where true;
delete from public.basepacks where true;
```

The live UBL Availability V2 database already has this fix applied.

The Next.js master commit route also now exposes structured Supabase errors instead of returning only `Master import failed.`.
